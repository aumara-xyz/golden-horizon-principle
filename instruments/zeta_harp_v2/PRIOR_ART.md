# PRIOR_ART.md — Zeta Harp v2

## Honest starting position

We have not performed a systematic prior-art search, and we do not claim novelty for any
individual component of this instrument. Visualization of the Riemann zeta function, of
the Riemann-Siegel formula, and sonification of zeta-related data all have existing
literature and existing artistic work. "No 'first ever' anywhere in this build"
(CLAIM_BOUNDARY.md) is the operating rule.

## Named precedents

- **J. Arias-de-Reyna, "X-Ray of the Riemann zeta-function", arXiv:math/0309433** — the
  named visualization precedent for drawing the structure of zeta on and off the critical
  line (the curves Im zeta = 0 and Re zeta = 0). Our deferred "X-Ray room" is named for
  this paper and would be an implementation of its idea, not a new one.
- **DLMF chapter 25.10** (Digital Library of Mathematical Functions) — the formula source
  for the Riemann-Siegel Z-function, theta function, and main sum used verbatim in
  MATH_SPEC.md. All mathematics in this build is standard.

## Sanctioned holding line

> We have not established priority. The intended contribution is the specific integration
> of validated Riemann-Siegel term geometry, direct time-compressed sonification,
> zero-crossing inspection, and immersive interaction.

This is the only novelty statement permitted in any copy, page, or note for this build.
If a closer precedent for the integrated form is found, this file is updated first and the
holding line is weakened, not defended.

## Obligations

- Any additional precedent discovered during the build is added here in the same commit as
  the feature it touches.
- Public-facing copy may cite this file but may not paraphrase the holding line into a
  stronger claim.
