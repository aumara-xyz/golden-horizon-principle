these rules:

   with repo access the owner grants), targeting a `review/<name>/...` path or the file
   the contribution amends. External contributors never merge.

   verifier's findings go in the PR thread. The owner adjudicates.
3. Attribution is preserved in the commit message and the ledger packet log.
4. The Do-Not-Claim rules, the Riemann fence, and the hash-level sign-off floor bind
   external contributions identically. A contribution that upgrades a claim's evidence
   grade without the corresponding receipts is declined regardless of author.
