# De-Circularized Boundary Probes

## Purpose

These probes follow the first boundary-collapse hardening battery.

The first battery tested whether the analogue scaffolds were internally coherent.
This battery tests whether they survive a stricter rule:

```text
truth labels are generated by hidden dynamics;
detectors see only public/projection features;
results are evaluated on held-out seeds.
```

## Probes

### CAC-002 - Hidden Collapse Predictor

Question:

```text
Can public drive history predict hidden collapse-like events better than amplitude-only and shuffled controls?
```

Result:

```text
FAIL
```

Main reason:

```text
amplitude-only outperformed the proposed public collapse detector
```

Interpretation:

The cavitation analogue remains useful as grammar, but this detector is not yet a hardened predictor.

### NET-002 - Topology Recovery Probe

Question:

```text
Can the correct topology be recovered from node streams and predict withheld write/witness/release labels better than wrong topologies?
```

Result:

```text
FAIL
```

Main reason:

```text
the true topology was selected, but wrong topologies were too close
```

Interpretation:

The net branch improved over the first run, but it still needs a sharper graph-sensitive regime before promotion.

### CAS-002 - Non-Circular Cascade Probe

Question:

```text
Can staged public projections beat flatter public compression without private leakage?
```

Result:

```text
FAIL
```

Main reason:

```text
nested projection beat baselines only weakly and did not reach the pre-set F1 threshold
```

Interpretation:

Nested Markov-blanket language remains promising, but the current toy is not strong enough for paper hardening.

## Overall Read

The deeper tests did what they were supposed to do:

```text
they blocked analogy promotion
```

No paper upgrade should be made from these results.

The next useful direction is redesign, not repetition:

- `CAC-003`: use physically better delayed-collapse features or explicit trainable public filters.
- `NET-003`: use graph regimes where topology changes propagation in a way flat values cannot imitate.
- `CAS-003`: run a depth sweep and require an optimal finite depth rather than automatic "more layers is better."
