The Zeta Harp

The Riemann-Siegel main sum as a four-stringed instrument, t in [100, 160].

1. The mathematics

On the critical line, the Hardy function Z(t) is real-valued and shares its zeros with ζ(1/2 + it). Its Riemann-Siegel main sum is

Z(t) = 2 · Σn ≤ √(t/2π) n-1/2 cos( θ(t) - t ln n ) θ(t) = arg Γ(1/4 + it/2) - (t/2) ln π ≈ (t/2) ln(t/2π) - t/2 - π/8 + 1/(48t)

Each term n is a "string." The sum over n ≤ √(t/2π) means a new string joins the chord each time t crosses a threshold:

Correction to an earlier draft of this idea: t = 2πn2 is the threshold at which string n is born — the value of t where n first satisfies n ≤ √(t/2π) and enters the main sum. It is not the string's frequency. The instantaneous angular frequency of string n at height t is d/dt [θ(t) - t ln n] = θ′(t) - ln n, so its instantaneous cyclic frequency (per unit t) is (θ′(t) - ln n) / 2π, with θ′(t) ≈ (1/2) ln(t/2π) - 1/(48t²).

Birth heights in this window: string 4 is born at t = 2π·16 ≈ 100.53, and string 5 at t = 2π·25 ≈ 157.08 — both visible in the plot below. At the listening point t = 130, exactly four strings are active. The remainder term of the full Riemann-Siegel formula, O(t-1/4), is omitted here; this page plots the main sum only.

3. The four strings at t = 130

Each string's instantaneous frequency fn = (θ′(130) - ln n)/2π is in cycles per unit t — far below hearing. To pluck it we multiply by a single disclosed scale factor, S = 2000 Hz per (cycle/unit t), the only mapping choice made, applied identically to all strings. Loudness is proportional to the string's true amplitude weight n-1/2.

String 4 maps to roughly 41 Hz — near the bottom of the audible band and quiet on small speakers. That is the honest consequence of one uniform scale factor; no per-string adjustment is applied.
