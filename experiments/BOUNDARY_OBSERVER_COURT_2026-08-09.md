## New results

- **BC-B — Path-descriptor confound (the four-factor decomposition).** A synthetic adversarial
  recorder tuning **only** withholding and ordering drove a committed-trace drift descriptor to
  within **0.26×** the same-condition noise floor of a pinned target shape (kill threshold 2×).
  **KILL:** any claim that a committed-trace descriptor evidences latent-process drift *without*
  emission-policy control is dead. Honest positive, reported without upgrade: a Lévy-area descriptor
  separated genuine process drift from policy drift at **AUC 0.809** against a class-frequency
  baseline's **0.066** — real as a descriptor of the recorder, never as evidence about the process.

- **BC-D — 27 minimality and the reference relation.** All **351** posture pairs of `{-1,0,+1}^3`
  are separated by a lane-query battery, so 27 is forced **only** by the axioms {3 semantic values ×
  3 independent lanes} — both design choices. Measured: an observer expressed as an external output
  function needs exactly **27** states, while the same query battery answered by an internalized
  state machine minimizes to **178** states — a **6.6×** blowup. "The observer is a reference
  relation, not a 28th state" is now a measured statement of standard automata theory; the program
  contributes the framing, not the theorem. **Kill condition #13 discharged:** 27 has no
  task-specific minimality beyond the product count, and no stronger claim may be made.

- **BC-MB — Markov blanket court.** A linear-Gaussian model of a governed-boundary dataflow that
  contains one write path bypassing the mediating surface yields conditional mutual information
  I(internal; external | boundary) = **0.086 nats** ⇒ **not** a Markov blanket. With every write
  path mediated, **7.6e-7 nats** ⇒ blanket-shaped. Ruling: "Markov blanket" is admissible only as a
  **design target**, never as a description of a running system, until every write path is mediated.
  This resolves B-024's own kill condition for this instance: the internal/blanket/external
  partition IS definable here, and it fails unless the boundary is total.

- **BC-F — Boundary-figure representation court.** A six-plane 4D figure is **injective, 729/729**
  over a six-lane ternary posture space (minimum pairwise frame distance 3.27) *when the postures
  actually drive the rotation angles*. A figure whose angles instead read only a running count and a
  history head does not witness the postures at all — a representation can carry a posture or not,
  and only wiring decides which. A 32-bit frame checksum reaches ~0.69 collision probability by 10⁵
  frames. This confirms and quantifies the standing fence: **the shape must never become a
  cryptographic verifier when direct digest verification is available.**

- **BC-CG — Selective disclosure and zero-leakage overlap.** An independent minimal RFC 6962
  reimplementation ran an adversarial matrix. The first-draft verifier was **caught by the matrix
  itself**, trusting prover-supplied fold directions so that the claimed position was unbound; it is
  preserved as a defective-instrument artifact and was repaired (direction derived from the index).
  v2: valid inclusion passes; wrong leaf, wrong position, wrong history, wrong generation, reordered,
  truncated, transplanted, and self-issued-presented-as-anchored all fail. A new **overlap protocol**
  (salted-PRF commitments, intersection-only reveal, mutual inclusion proofs) found all 40 planted
  shared leaves with 0 false intersections and **0 bits** of non-overlap leakage. Only membership
  results appear — membership verified, with occurrence, execution and world-truth standing
  permanently unproven. No aggregate trust score exists in any output.

- **BC-V02 — Topological memory (V0.2).** This is the **first computation of a genuine knot
  invariant** anywhere in the program (Fox 3- and 5-colorings from projected diagrams of unknot,
  trefoil and figure-eight loops). It also establishes a corpus fact: the prior toy "knot" arc used
  index neighborhoods and computed no invariant at all, so it **never tested** the topological-memory
  proposition in either direction. Two instruments — a v1 and a pre-filed amended v2 — both **failed
  their own sanity gate** (the invariant was not stable enough under topology-preserving deformation,
  and the strand-passage operator did not reliably change topology). Per the pre-filed stop rule,
  there is no v3. **Verdict: H2 UNDETERMINED — not tested, and probably not answerable by this class
  of cheap instrument.** The discriminating form remains a genuine anyon fusion-tree code (the
  AH.4-P1 family) or a persistent-homology instrument with a stability guarantee. Convergent with
  AH4-P1-POWERED: topology-as-memory stays unsupported until a stable instrument tests it.

## Toy demotions verified this session

Two toy results in the private engineering corpus were demoted by verified computation. A
"Fibonacci wins the core channel" result reduces to a **minimal-factor-complexity (Sturmian)
artifact** — the Fibonacci word has the fewest distinct k-mers, an established property shared by
every irrational-rotation word, so φ is not distinguished; the same toy's "erasure" operator was an
identity map and its "recovery" metric mixed in the ground-truth vector. A "generic ternary wins the
wrong-signal lane" result reduces to **bin-support geometry**: a fixed index shift on a shared
vocabulary leaves the sparsest histogram exactly orthogonal to itself. Neither reopens any φ lane;
together they close the last places φ appeared to win in the toys, which is convergent with the
canon verdict **φ lives in the architecture, not the dynamics.**
