# Sonoluminescence-To-Aukora Test Chain

## Status

This is an engineering research chain, not physics evidence.

The sonoluminescence / acoustic-cavitation breakthrough contributed a disciplined analogy:

```text
continuous drive + nonlinear boundary collapse -> localized readable event
```

GHP imports only that narrow structure. It does not import over-unity claims, scalar-wave claims, consciousness proof, or a derivation of time.

## Why It Mattered

Before this branch, the write-law question was too poetic:

```text
How does hidden process become public record?
```

The conservative sonoluminescence analogy sharpened it into a testable software question:

```text
Can a governed boundary convert unresolved internal pressure into a typed public trace without leaking private state or authority?
```

That question directly spawned the Aukora-facing HRT / witness / Accord / MDL process-memory lane.

## Aukora Handoff Law

Only this invariant should move toward the Aukora kernel:

```text
Canonical receipts remain truth.
Telemetry may describe boundary mode.
Telemetry may guide offline analysis or advisory proposal context.
Telemetry may never authorize action.
MDL summaries may never replace receipts.
Private state and authority must remain unrecoverable from public traces.
```

## One-Sentence Safe Summary

The sonoluminescence branch did not prove GHP physics; it sharpened the write-law into a controlled boundary-telemetry program, which now gives Aukora a safer way to study how hidden process becomes public, replayable, non-authorizing memory.
